# Eta IntelliSense icon

`assets/icon.png` is the project icon used by the extension manifest and README. The square PNG is 1,254 × 1,254 pixels and can also be reused for project listings and social profiles.

The mark combines the Greek eta glyph with code brackets. Its intended palette is ink navy (`#191C2D`), coral pink (`#FF477E`) and warm off-white (`#F7F5F2`).

Generated with the built-in image-generation tool, then refined with the same tool. The final generated image is stored in the repository; no image service or build dependency is required to use it.

## Initial generation prompt

```text
Use case: logo-brand
Asset type: finished square PNG icon for the VS Code Marketplace and the Eta IntelliSense open-source extension.
Primary request: Create one professional, simple, flat developer-tool icon. The mark is a bold, carefully drawn lowercase Greek eta glyph "η" centered between two compact angle brackets, forming "<η>". The eta should be unmistakably a Greek eta with its descending right stem. This is an original project identity for Eta template language support.
Scene/backdrop: an entirely solid deep ink navy square, approximately #191C2D, edge to edge.
Style/medium: crisp vector-like flat geometry, clean antialiased edges, restrained and polished. No hand-drawn texture.
Composition/framing: one centered unified mark filling about 68% of the square width, substantial balanced margins, bold strokes and open internal spaces that remain legible at 32px. The central eta is the visual focus; brackets are smaller and evenly spaced.
Color palette: eta in bright coral-pink approximately #FF477E, angle brackets in warm off-white approximately #F7F5F2, navy background. Flat solid colors only.
Text (verbatim): "<η>" as the icon symbol only. No name, subtitle, additional letters, or caption.
Constraints: deliver just the finished icon as a square 1024x1024 image. No presentation board, border, gradients, shadows, glow, texture, 3D, photographic lighting, mockup, tiny details, sparkles, watermark, or extra decoration.
```

## Final refinement prompt

```text

Keep the exact centered <η> composition, Greek eta silhouette, angle brackets, spacing, square canvas and margins.
Make the finished artwork completely flat: use uniform solid #191C2D for every background pixel, uniform solid #FF477E for the eta, and uniform solid #F7F5F2 for both brackets, with smooth antialiased edges only. Remove every trace of texture, grain, mottling, lighting, gradients or shading from every fill. Preserve the bold shapes and professional simplicity. No additional text, shadow, border, watermark or decoration. This should look like a clean exported vector icon, not a painted illustration. Square PNG icon.
```
